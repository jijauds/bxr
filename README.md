# bxr

BXR is a mobile application made for analyzing boxers' performance and efficiency in doing fundamental boxing moves. It uses two-dimensional (2D) pose estimation and angle heuristics to give feedback. This is a project for the Software Services Laboratory under the Department of Computer Science in the University of the Philippines - Diliman.
